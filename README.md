# DNT Volunteer Hub

Sistem de evidență și administrare organizațională pentru Direcția Națională a Tinerilor.

> „Every Volunteer. Every Branch. One Organization.”

## Conținut
- `index.html` – aplicația completă (un singur fișier, fără build, logoul este inclus în el).

## Rulare
Deschide `index.html` în browser sau activează GitHub Pages (Settings → Pages → branch `main`, folder `/root`).

## Stare actuală
Prototip funcțional: dashboard, registru voluntari, cereri de înscriere, organigramă, filiale, departamente, ore, audit log.
Datele se salvează local în browser (localStorage). Urmează: Supabase/PostgreSQL, autentificare, RBAC și RLS.
